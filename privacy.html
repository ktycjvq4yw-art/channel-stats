Privacy policy: channel-stats

Last updated: 2026-10-30

channel-stats is a private tool used only by the owner of one YouTube channel to read that channel's own statistics.

What it accesses

With the scopes youtube.readonly and yt-analytics.readonly it reads channel and video statistics (for example views, watch time, retention and traffic sources) of the signed-in user's own channel. It has no write access and cannot upload, edit or delete anything.

Where the data goes

The login token and the statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties or sent to any server other than Google's APIs. No cookies or tracking are used on this website.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

channel-stats' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
